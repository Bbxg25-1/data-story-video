# 数据解释短视频

一个轻量的个人表现规范：**用户认定的重点优先，先看全貌，再突出变化，必要时放大差额。** 适用于有比较、数量或状态变化的题材，不限定基金。

规则集中在 [SKILL.md](SKILL.md)。不附带视频、账户截图、音乐、字体或渲染引擎；用现有制作工具执行。

## 使用

把本目录放进支持 Agent Skills 的工具的技能目录，或让支持读取文件的助手参考 `SKILL.md`。在 Codex 中可用：

```text
用 $data-story-video 做一个无口播对比视频。
这次重点是两种方案最后的差额：保留完整对比，再拉框放大差额。
解释时音乐平缓，结果揭示时加强。先给我大纲。
```

每次说清“这一条最重要的是什么”，比增加模板条款更有用。配色和流程是默认值，当前任务要求优先；不承诺爆款或保证节省额度。
