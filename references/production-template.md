# 画面、音乐、音效与动效模板

用于同一账号的数据解释视频。目标是让观众认出一致的制作风格，同时让每期故事、图表和节奏由内容决定。以下为设计默认与试调方式，不是平台效果保证，也不意味着某首配乐或某份旧成片已经获用户认可。

## 固定哪些，改变哪些

| 系列中保持一致 | 每期按内容调整 |
|---|---|
| 字体家族、数字字体、字号层级 | 标题长度、术语、数值与单位 |
| 背景、正文、重点的颜色含义 | 对象、照片、图表类型、资产配色 |
| 普通元素的入场方向和减速手感 | 动作距离、图表演示过程、阅读停留 |
| 提示音各自表达的意思 | 是否需要声音、揭示时刻、强调强度 |
| 主音乐的风格与段落衔接方法 | 本期情绪、旋律、配器、音区和密度 |
| 封面的识别元素与信息层级 | 核心图表、标题、日期及主题 |

可复制[分镜模板](../assets/storyboard-template.md)起稿。沿用现有制作引擎和工程组织，不为模板重建工具链。

## 视觉与文字基准

- 默认黑白主体、红色强调，先写清颜色含义。红色可表示本片重点，不自动等于收益为正或风险；图表仍保留正负号、名称和单位。同一片的颜色含义保持一致。
- 中文正文沿用一套字体及字重，关键数字可使用清楚的等宽字体。系列继承已认可的字号层级；1920×1080工程可从标题约80—120px、主数字约130—190px、正文约56—72px、图表标签约50—60px起稿，按字数和手机观看尺寸调整。这些是设计起点，不能据字号数值断言已可读。
- 去掉填空小字、装饰英文、制作脚注和画面中的“场景图为AI示意”等制作说明。来源、素材生成记录和详细口径放在附件；“假设投入”“算术示意”、币种及关键条件以简短、可读正文保留。
- 每镜头一个主焦点：主图或主数字最先被看到，解释和emoji辅助理解。底部字幕承担解释或承接，不反复逐字重复已经醒目的标题。
- 照片提供场景与材质，正文区域压低对比度；真实图表有稳定的阅读区域。背景、曲线、日期卡和标题不要争抢同一位置。话题或时空改变时考虑换背景，原图仍有叙事作用时可继续沿用。

## 六种可选镜头

这些是可选模块，不是一条视频必须依次播放的六段。镜头时长按技能正文及[停留时间参考](pacing-and-shot-changes.md)试调。

| 镜头职责 | 画面与信息变化 | 动作手感 | 音乐与音效 |
|---|---|---|---|
| 提问 | 首帧直接给对象、冲突或疑问，再补一个有力例子 | 清楚出现；可局部推进，避免空片名 | 音乐尽早建立脉冲；默认不砸击，关键疑问可有轻提示 |
| 证据 | 真实曲线、日期或状态过程，保留对象与单位 | 随时间画线或分步标点，坐标稳定，结束后读数 | 保持主音乐连续；只有定位确有需要时用轻点声 |
| 对比 | 两个对象同屏，同尺度突出差额 | 先建立双方，再显出差额或引线；读数时停稳 | 结果揭示可用一次柔和提示，音乐稍抬起 |
| 演算 | 条件、步骤、公式、结果逐步出现 | 在同一构图中增加信息；不要每一步重置整个画面 | 乐句继续向前，步骤可对齐半小节；结果跨拍保留 |
| 转折 | 新证据、预期被推翻或关键限制出现 | 精简旧元素，重点变色、局部放大或短印章择一 | 可用短和弦、配器变化或短暂留白，声音对准发现 |
| 收束 | 用一句具体答案回应开头，并保留最有用的对照 | 动作收轻，重点稳定停留，简洁离场 | 音乐解决或减少配器；不额外堆提示声，不强塞泛泛口号 |

emoji跟随角色的期待、疑惑、惊讶和理解变化；图标代表对象时配名称。不要每个新镜头都换一个表情来代替信息推进。

## 常用动作与效果强度

| 使用场合 | 可先试的处理 | 需要保留的阅读条件 |
|---|---|---|
| 普通文字或卡片进入 | 约0.2—0.35秒的淡入、短距离单向移动、减速落稳 | 入场完成后再计阅读；相邻元素可作为一组错峰 |
| 关键数字揭示 | 约0.3—0.45秒的遮罩或轻微缩放，尽快稳定到真实值 | 不长时间滚数，数字、单位与正负号一起可读 |
| 曲线或过程演示 | 时长按实际步骤安排，不套普通文字入场时长 | 坐标、比例和参照不动；过程完成后留读图时间 |
| 场景转接 | 短淡出/淡入、遮罩承接或语义明确的硬切 | 避免两屏正文交叉叠成重影；同对象尽量保留位置或方向 |

普通解释使用基础效果；一般发现可加一条引线、底色或一次局部强调；主要转折才考虑更明显的推近、局部放大或印章。每个主要落点选一种显著效果，让声音与它共同强调。默认不用反向蓄势、反复回弹、旋转、抖屏和全屏闪白。

图表的局部放大保留原图参照、尺度与放大关系。主图、数字、emoji和背景不要同时运动；读数时稳定。

## 音乐的三种状态

优先延续用户已认可的风格。没有认可记录时选用适合主题的暂定主音乐，通过带声短样片判断；不要把“已导出”当作“已认可”。

1. **建立与解释**：音乐较疏，给文字和图表留空间；节拍清楚但不催促。
2. **推进与发现**：同一风格下增加音区、节奏密度或配器，关键结果落在乐句或重音附近；读数时间可以跨拍。
3. **收束**：减少配器或让和声解决，结尾有落点，不把中间一段音乐硬截断。

优先让同一首主音乐跨多个镜头连贯发展；内容需要时再换曲，衔接保持自然。不要每换画面就重启BGM、拼贴同一小段旋律，或把所有镜头硬拉成整小节。

音轨统一调混，避免突然过响、削波或局部音量突变。是否听得舒服必须带声播放；峰值、响度和节拍对齐只证明相应技术事实。

## 让提示音有一致的意思

可先用少量声音家族建立系列识别，再按需要扩展。素材可更换，但同一声音家族的用途保持清楚。

| 声音家族 | 本模板赋予的用途 | 使用分寸 |
|---|---|---|
| 轻点、短拨弦 | 定位、选中一个节点、开始一个离散步骤 | 轻、短，普通字幕出现可完全无声 |
| 柔和提示、圆润短铃 | 数字或比较结果揭示 | 关键结果一次即可，避免连续尖锐叮声 |
| 短和弦、低而柔和的重音 | 主要转折、重要限制或高潮发现 | 只用于值得强调的落点，也可由配器变化或短留白代替 |

转场不默认附带whoosh；不用沙沙扫动声和密集砸击。画面普通、声音很重会显得刻意，声音强度要与信息重要程度相称。背景音乐已有明显落点时，额外音效可以省略。

所用音乐、提示音、图片和字体保留来源及使用依据。以上定义的是声音用途，不意味着已经建立或授权了具体音频素材库。

## 使用模板时交付什么

从本期主题挑选镜头类型，填写分镜中的视觉步骤、阅读时间及声音。优先实现一段能代表本期画面和音乐的带声样片；按用户已授权的范围继续或交付，沿用技能中的阶段边界。

每段分别保存画面、字幕、BGM和动作音效，再拼接；保留本期分镜、数据计算、来源、风格选择与最终导出文件。记录本期调整了哪些参数，方便只重做受影响模块。固定制作语言、留下内容变化空间，避免所有选题都套成同样的段数、时长和情绪曲线。
