# 画面变化与停留时间

用于数据解释视频的前五秒、镜头切点、数字停留和音乐节奏。以下参数是便于起稿的个人默认，按内容复杂度、用户反馈和实际样片调整；广告案例不等于知识视频的统一标准。

## 先定义在计什么

- **画面组持续时间**：同一个主要构图或叙事单元维持多久。组内可以有运动、分屏变化和多个信息步骤。
- **信息更新间隔**：何时新增一个有用的数字、标记、结果或解释。它可以发生在同一构图中。
- **稳定阅读时间**：关键内容完整出现并落稳后，到离场前的时间。入场、数字滚动和淡出不计入完整阅读。

分镜至少记录：起止时间、主要焦点、变化原因、动画落稳时刻、结果读数时长、下一个新信息和音乐落点。避免一边入场一边切走，或用很长的静止画面等待音乐。

## 前五秒如何安排

可先试约3个清楚的视觉状态，形成“问题或冲突 → 例子或关键数字 → 对比或进一步疑问”。例如：

| 时间 | 视觉任务 | 连续性 |
|---|---|---|
| 约0—1.5秒 | 首帧让人知道在问什么或发生了什么 | 直接给主体、冲突或图表，不先播空片名 |
| 约1.5—3秒 | 显现一个具体例子、证据或主数字 | 沿用对象、布局和视线方向，让焦点容易找到 |
| 约3—5秒 | 补出差额、条件、反差或下一步问题 | 前一个数字可以继续保留，保障落稳后的阅读时间 |

这不是3次硬切的配额。图表较复杂、日期较多或数字需要比较时，优先在同一构图内逐步呈现；熟悉物体的简短蒙太奇可以更快。每次变化要推进理解，不能只把同一句话换个位置或换一张无关背景。

不要把一组需要几秒阅读的完整数据在第3秒清空，只为了完成第3个状态。把新标记加在稳定的原图上，也能让观众感到画面在推进。

## 什么时候换场，什么时候继续原画面

| 情况 | 优先处理 |
|---|---|
| 话题、主体、时空或比较条件改变 | 换主要画面或明确过渡，让观众知道进入新段落 |
| 同一笔钱、同一条曲线、同一个计算的下一步 | 保留对象和参照，补日期、数值、引线或结果 |
| 需要比较两个结果 | 尽量同屏保留，避免让观众记住上一镜再心算 |
| 关键结论刚出现 | 动作停稳，给足读数时间，再推进 |
| 阅读完成、旧信息不再承担比较任务 | 精简旧元素，进入下一步，避免空等 |
| 一组讲解需要6—8秒或更长 | 分步演示、加标记或改变焦点；读数时主图稳定 |

具体停留时长使用技能正文的试调表。术语、单位、多个日期、公式和图表会增加理解负担；可以缩短文案、拆步骤或延长阅读，不以一味加快切镜解决。

## 音乐怎样带动变化

一拍时长为60/BPM秒。例如80 BPM时，一拍0.75秒、两拍1.5秒、四拍3秒；100 BPM时，一拍0.6秒、两拍1.2秒、四拍2.4秒。选择与阅读相容的节点安排动作、补入信息或换场。

主要转折可落在乐句、小节起点或明显重音上；同一场景的次要信息可以在半小节补入。关键数字允许跨拍保留，解释段也可以跨多个小节。音乐的强弱、音区、密度和停顿配合内容起伏，避免所有元素都在鼓点上撞入。

检查带声音的正常速度样片：视线能否跟上，上一条是否读完，音乐是否催促了不该加速的计算，停留期间是否仍有信息在推进。波形、节拍表或静音播放只证明相应的技术事实，不能证明听感或传播效果。

## 参考依据与边界

以下来源于2026-11-14的研究记录，作为解释原则的依据。以后需要当前平台规则、热榜或新案例时重新核查，不称这些经典案例为当日热门榜单统计。

- [Google/YouTube ABCD指南](https://services.google.com/fh/files/misc/youtube_google_abcd_reference_guide_en.pdf)：建议广告前5秒出现超过两个画面。这里是创意画面/镜头语境，不是编码帧率；指南基于相关性数据，并非对所有品牌的统一保证。本技能的“约3个视觉状态”是适配数据讲解的起稿方法。
- [TikTok Creative Codes](https://ads.tiktok.com/business/en/blog/creative-best-practices-top-performing-ads)：强调音乐、运动、转场、文字和emoji共同刺激注意，没有要求所有画面停同样秒数。
- [Netflix简体中文字幕指南](https://partnerhelp.netflixstudios.com/hc/en-us/articles/215986007-Chinese-Simplified-Timed-Text-Style-Guide)：普通成人字幕阅读速度上限为每秒9字，18字按该上限至少约2秒。它是字幕交付规范；理解图表和计算另需时间，不能直接当作短视频最佳节奏。
- [Nike《You Can’t Stop Us》原片](https://www.wk.com/work/nike-you-cant-stop-us/)：本次以主要构图换组计时，前六组约5.3、4.2、2.0、2.5、1.7、3.8秒。用候选切点结合前20秒半秒采样和换组后画面复核，读数取约数；分屏擦拭等内部变化未一律算新组。长组内有持续动作，不能据此推导爆款都每2秒切一次。
- [Old Spice案例及原片](https://www.wk.com/work/old-spice-smell-like-a-man-man/)：本次逐秒抽查的约30秒主体围绕同一人物持续推进，约12秒进入甲板、约27秒拉远显露骑马，期间道具和动作不断变化。时间为约数，示范长构图的内部推进。

研究实际案例时记录版本、选取片段、计时单位、观察方式和误差。自动场景检测可能把闪光、擦拭或运动误报为换镜，也可能漏掉渐变与局部替换；复核后才能称为观察到的切点。无法取得或查看的视频不填精确秒数，不把个别案例平均值当作整个热门视频群体的统计。
